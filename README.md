🎬 Netflix Clone

A Netflix-inspired website built using HTML, CSS, and JavaScript. This project recreates the look and feel of Netflix with a modern dark theme, responsive layout, movie posters, and interactive elements.

🚀 Features

Netflix-inspired user interface.

Responsive design for different screen sizes.

Navigation bar with Netflix logo.

Language selection option.

Sign-in button.

Hero section with background image.

Email input section.

Trending movies section with movie posters.

Interactive elements using JavaScript.

CSS styling, hover effects, and layout adjustments.

🛠️ Technologies Used

HTML5 – Website structure.

CSS3 – Styling, layouts, animations, and responsiveness.

JavaScript – Interactive functionality.
